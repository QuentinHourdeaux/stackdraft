# PR 16 — v0.1 Hardening

Depends on PRs 01–15.

## Required context

Read every durable document in `docs/`, the current README, and the complete
merged application. The v0.1 specification is the acceptance source.

## Outcome

Verify Stackdraft v0.1 as a portable tool suitable for daily personal use.

## Included

- End-to-end acceptance pass against `docs/v0.1-spec.md`
- Consistent loading, empty, validation, and recoverable error behavior
- Keyboard navigation and visible-focus audit
- Desktop and laptop responsive-layout audit
- Container build, health, restart, and persistence verification
- Stop-and-copy backup and restore verification
- Documentation corrections discovered during verification

## Fixed implementation details

- Create a temporary acceptance matrix mapping each criterion in
  `docs/v0.1-spec.md` to an automated test or a documented manual verification.
  Criterion 12 is explicitly deferred to PR 17; remove the temporary matrix
  before merge after every technical row passes.
- Test Docker from a clean temporary data directory rather than the developer's
  normal `./data`.
- Perform backup restoration into a second clean temporary deployment and verify
  representative States, a Stack, and a Draft through the API or UI.
- Test at minimum 1280×720 and 1440×900 desktop/laptop viewports plus
  keyboard-only navigation.
- Fix only defects or missing acceptance behavior. Record newly desired
  capabilities as post-v0.1 observations in `project-evolution.md`.

## Not included

- New product capabilities
- Deferred v0.1 non-goals
- Cosmetic redesign unrelated to a verified usability problem

## Acceptance

- Every v0.1 acceptance criterion is demonstrated or covered by an automated
  check.
- A clean Docker Compose deployment initializes successfully.
- Data survives container replacement and host restart.
- A backup restores successfully into a fresh deployment.
- No known issue blocks several days of real personal use.
- README commands and security warnings match the verified deployment.
- `deno task ci` passes.
